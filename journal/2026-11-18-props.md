# Props

Trip to the vintage stores on Notre Dame held some interesting metal objects- a copper goblet and a box of vintage keys in the goth woo store, some antique light fixtures. No appropriate clocks.

Having a large single conductive prop doesn't seem good to me (at least not with the current setup.) If you combined it with a bunch of smaller props (say the goblet surrounded by the keys) the goblet would get most of the attention and make the results feel very same-y. If I rebuilt it so that there's some kind of subtle theremin-y sensitivity to the main prop, it would be less likely you'd get the same results, which would make it feel like a purely random button. Some nice tactile object with multiple separate contacts that feel evenly emphasized, maybe located in a fingertips on hands arrangement still feels best. I am concerned about making something nice enough in 10 days though. The alternative is make something purposely 'default' untreated wood etc. I'd rather not do this, although if the screen is the main light source, something that is mostly featureless that catches the light well could successfully background itself... as long as the contacts are noticable.
